# 快速机械运动 · 离线时间采样运动模糊渲染器

在一帧快门开启区间内，对**旋转叶片的连续转动**与**小球的连续位移**做真实的
时间采样：每个曝光时刻都由连续时间场景独立求值、经工作进程独立光栅化，再按
所选快门曲线的权重合成为运动模糊图。它不是“渲染一张锐利图再施加方向模糊”，
遮挡关系、透明物体与光照都随时间真实变化。

## 快门采样的图形入口（主要用法）

```bash
python3 -m motion_blur.webui
```

浏览器打开 <http://127.0.0.1:8000/>，在「快门采样出图任务」面板中：

- 调整**帧率、帧号、快门角度、帧内快门开启偏移、时间样本数、快门曲线、
  分辨率、工作进程数**；
- 采样区间（帧周期、帧起点、快门开/闭的**绝对时刻**、曝光时长）随参数
  实时计算并展示，贴近帧边界的采样时刻在权重柱上以紫色标出；
- 「采样权重」柱图显示每个曝光时刻**实际归一化后的权重**，异常时刻
  （遗漏=红、重复被拒=黄）直接在柱图上标出；
- 可注入**首次故障样本**（验证重试）与**重复投递样本**（验证去重）；
- 结果区以分页方式查看：**运动模糊积分图 / 高密度时间参考 / 误差图 /
  曝光内单个时刻状态**，并给出平均/最大像素误差与合并记录。

参数或渲染异常以红色横幅在快门采样界面提示，不会被静默吞掉。

## 命令行（仅辅助快门采样）

图形面板是主入口；CLI 用于无界面环境与脚本化验证：

```bash
# 只计算并打印快门采样计划（时刻、位置、权重、曝光区间），不渲染
python3 -m motion_blur.cli schedule --fps 24 --angle 180 --samples 24 --curve gaussian

# 非对称快门 + 指定帧号：帧 #7、帧内偏移 5ms（越帧会被拒绝并返回非零退出码）
python3 -m motion_blur.cli schedule --fps 24 --angle 90 --frame 7 --t-open-offset 0.005

# 执行完整离线渲染，产物写入 --out 目录
python3 -m motion_blur.cli render --out job_out \
    --fps 24 --angle 180 --samples 24 --curve trapezoid \
    --workers 4 --reference-samples 256 \
    --fail 3,7        # 让 #3、#7 时刻首次执行失败，验证重试不累加
    --duplicate 5     # 额外重复投递 #5 时刻，验证去重
```

## 完整链路

| 阶段 | 模块 | 说明 |
| --- | --- | --- |
| 快门采样 | `shutter.py` | 帧率×快门角度确定曝光时长；`frame_index` 与帧内开启偏移 `t_open_offset` 定位快门的**绝对时间区间**；分层中点生成确定性时刻；权重取自快门曲线并归一化到和为 1 |
| 连续时间求值 | `scene.py` | 叶片角度、小球位姿、光照增益/方向/环境光全部由绝对时间 `t` 解析求值 |
| 工作进程渲染 | `render.py` + `pipeline.py` | 每个时刻一个任务，经 `multiprocessing` 进程池光栅化为锐利状态图 |
| 去重合并积分 | `integrate.py` | 以样本 index（即曝光时刻）为键合并；重复贡献拒绝、遗漏时刻报告、接受权重重归一化 |
| 参考对照与误差 | `pipeline.py` | 同区间同曲线用高密度时刻重渲染作为参考，逐像素计算平均/最大绝对误差并出误差图 |
| 出图面板 | `webui.py` + `static/` | 离线 HTTP 面板，后台线程跑多进程任务，REST 轮询状态与产物 |

### 帧号换算与跨帧边界（时间映射）

样本的**绝对采样时刻**严格按

```
t = frame_index * frame_period + t_open_offset + u * exposure
```

计算，连续时间场景只对该绝对时刻求值。代码刻意不做帧周期取模回绕：
一旦 `t_open_offset + exposure` 越过本帧周期（快门跨入下一帧），
`build_schedule` 直接抛出 `ValueError`，由面板以红色横幅、CLI 以非零
退出码暴露，而不是把运动物体静默取样到错误相位。`Sample` 同时保留
`time`（绝对时刻）与 `frame_time`（帧内时刻），便于核对二者关系。

时间映射的可复跑回归在 `tools/shutter_time_regression.py`：用解析匀速
直线与匀速旋转轨迹对照解析积分，证明正确映射收敛、并保留「取模回绕」
与「丢弃帧号」两种错误映射的失败证据（误差量级 1e-1 vs 正确映射 1e-16）。
运行：`python3 tools/shutter_time_regression.py`。

### 为什么不是方向模糊冒充

方向模糊只需要一张锐利图 + 一个运动矢量，无法表达遮挡随时间的变化。本渲染器
对每个曝光时刻独立调用 `scene.evaluate(t)`：叶片转到不同角度、小球移到不同
位置、前景半透明遮挡条与它们的轮廓重叠关系逐帧变化，光源以 8 Hz 闪烁且方向
连续旋转。积分图是这些**不同场景状态**的加权平均，误差图也证实残差集中在
真实的运动边缘上。

## 采样正确性与可发现的异常

- **权重遵循快门曲线**：内置 `box`（矩形）、`trapezoid`（梯形软快门）、
  `gaussian`（中心权重高）、`double_pulse`（双段曝光）四种曲线。
- **区间随参数变化**：曝光时长 = 帧周期 × 快门角度 / 360；帧率或角度改变后，
  采样时刻与范围整体重算（360° 即覆盖整帧）。
- **重复时刻可被发现**：同一 index 的结果只接受一次，重复者进入
  `merge.duplicates_rejected`，绝不二次累加。
- **遗漏时刻可被发现**：失败且超过重试上限的时刻进入 `merge.missing`，
  面板柱图标红，剩余接受样本重新归一化。
- **重试记录实际接受的样本**：`merge.attempts` 记录每个时刻的实际尝试次数。

## 时间一致性的支持范围

**支持：**

- 透明物体：前景两条半透明遮挡条在每个时间样本内做标准 source-over
  alpha 合成，叶片与小球从其后穿过时颜色混合与轮廓重叠随时间正确变化；
- 时变光照：光照增益闪烁、方向连续旋转、环境强度缓变，背景与所有物体在同一
  时刻共享同一光照状态，积分结果是真实的时变光照平均；
- 逐时刻真实遮挡：所有深度关系在每个时刻由画家算法重新排序，无运动矢量外推。

**当前不支持（明确边界，而非隐藏情形）：**

- 透明物体只做 alpha 混合，**不模拟折射、焦散**，不会弯折背景；
- 光源为解析方向光，**不含阴影投射与全局光照**；
- 运动限于二维平面，无三维相机与景深。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：快门区间随帧率/角度变化、权重归一化与非均匀曲线、重复时刻去重不累加、
遗漏检测与权重重归一化、重试次数记录、高密度参考误差随样本密度下降，以及
透明合成与时变光照的基本一致性；时间映射侧覆盖帧号平移绝对时刻、帧内时刻
保持不变、跨帧窗口被拒绝（不静默回绕）、解析匀速/旋转轨迹积分与曝光重心
回归、渲染像素只由绝对时间决定；另含面板服务的参数校验、错误状态码与
路径穿越防护（共 39 个测试）。

时间映射的独立可复跑证据见 `tools/shutter_time_regression.py`。

## 产物

每次任务输出：`integral.png`（运动模糊）、`reference.png`（高密度参考）、
`error.png`（×4 增益误差图）、`samples/sample_NNNN.png`（各接受时刻锐利状态）、
`metadata.json`（采样计划、权重、合并记录、误差指标）。

仅依赖 Python 标准库，PNG 编码与 HTTP 服务均内置，可完全离线运行。
